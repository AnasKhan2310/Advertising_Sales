# Advertising Sales Prediction 📊  

This project uses machine learning to predict product **Sales** based on advertising budgets across **TV**, **Radio**, and **Newspaper** channels.  
It demonstrates data cleaning, visualization, and model evaluation using Python.

## 📂 Project Structure
- `Advertising_Sales_Dataset.ipynb` – Main Jupyter Notebook with data analysis & modeling steps  
- `Advertising.csv` – Dataset used in the notebook (TV, Radio, Newspaper ad spend, Sales)

## 🚀 Features
- Data cleaning and preparation
- Exploratory Data Analysis (EDA) with Matplotlib and Seaborn
- Linear Regression model for predicting Sales
- Model evaluation using RMSE, MAE, and R² metrics

## 🛠️ Tech Stack
- Python 3.x
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## 📊 Workflow
1. Load dataset & clean unnecessary columns  
2. Visualize relationships between Sales & ad channels  
3. Train/Test split the data  
4. Fit a **Linear Regression** model  
5. Evaluate using:
    - Root Mean Squared Error (RMSE)
    - Mean Absolute Error (MAE)
    - R² Score  

## 📈 Results
- The model accurately predicts Sales based on advertising spend.
- Provides insights on which channel influences Sales the most.
